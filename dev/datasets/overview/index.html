Datasets¶

torch-pointcloud provides loaders for the common point cloud benchmarks. Each sample is one dict, the format transforms consume.

Datasets with an automatic download take download=True; the others must be downloaded manually. S3DIS, ScanNet and ScanObjectNN are released under terms of use: read them (each class links its terms_url), then pass accept_terms=True next to download=True. The original files are kept in root/<dataset>/raw, and the cache built from them in processed.

from torch_pointcloud.datasets import ModelNet40
from torch_pointcloud.utils.data import PointCloudDataLoader

dataset = ModelNet40(root="data", train=True, download=True)
dataloader = PointCloudDataLoader(dataset, batch_size=32)

PointCloudDataLoader is a DataLoader using the packed-batch collate of torch_pointcloud.utils.data.

Tasks¶

  • Classification

    ModelNet and ScanObjectNN: meshes, presampled clouds, difficulty variants.

  • Segmentation

    Indoor rooms and outdoor LiDAR, their splits, and the label conventions.

  • Part segmentation

    ShapeNetPart: 16 categories, 50 global part ids.

  • Detection

    SUN RGB-D, KITTI, nuScenes, and batching ragged boxes.

Base class¶

Dataset Task
PointCloudDataset
Base class of the loaders: the root/<name>/raw and processed paths and their existence checks. It has no download, process or transform hook; a loader implements __getitem__ and __len__, and any torch.utils.data.Dataset returning sample dicts works as well.		 (any)

Dict keys¶

Every loader returns sample dicts keyed by DataKeys (torch_pointcloud.utils.data): pos, color, normal, segment, instance, label, box, face, ... The data format page lists each key with its shape and dtype, and how collate batches it; the task pages below note what each dataset adds.
